Everything in one tiny box

Glimmer is a pretend retro computer: 256×144 pixels, 32 colors, four sound channels and a fixed CPU budget. The tools for making a game come built in, and every machine runs a cart exactly the same way.

🛠️ Built-in editors

Code, sprites, maps, sound effects and a music tracker, all inside the console.

🌙 Lua 5.4

Autocomplete, signature hints, a debugger, and hot reload while the game runs.

🎵 A real synth

Eight waveforms, custom wavetables, slides, vibrato and arpeggios, made live.

🖼️ Carts are pictures

Export a game as a PNG with the whole cart hidden in its pixels.

🌐 Share anywhere

Links that play in any browser, single-file HTML games, and standalone apps for itch.io.

📱 Touch ready

The web player has on-screen controls, so your games work on phones too.

Open the console, type new, press Alt+2 for the code editor, and Ctrl+R to run.

Put a game on your page

<script src="https://armd.one/glimmer/embed.js"></script>
<glimmer-player cart="sprout"></glimmer-player>

Point src at any .glim or .png cart instead, or paste the data from the shell's share command.
